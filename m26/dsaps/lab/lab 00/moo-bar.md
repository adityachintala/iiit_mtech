# Moo-Bar

## Problem Statement

You are given an integer N.

You have to print the numbers from 1 to N in new line.
But for every multiple of 5 print "Moo", for every multiple of 7 print "Bar" and for every multiple of both 5 and 7 print "MooBar" instead of the number.

## Input Format

The first line contains a single integer t - the number of test cases.

Each test case consists of a single integer N.

## Constraints

1<=t<=100

1<=N<=10^4

## Sample Input 0

```
3
7
10
3
```

## Sample Output 0

```
1
2
3
4
Moo
6
Bar
1
2
3
4
Moo
6
Bar
8
9
Moo
1
2
3
```
