# Not a fibonacci

## Problem Statement

Given an Integer N.

Output fib(N).

fib(N) is defined as fib(N) = fib(N-1) + fib(N-2).

and fib(0)=0, fib(1)=1.

## Input Format

First line contains a single integer N

## Constraints

0<=N<=40

## Output Format

Print a single Integer, fib(N).

## Sample Input 0

```
2
```

## Sample Output 0

```
1
```

## Explanation 0

fib(2) = fib(1) + fib(0) = 1+0 = 1
