# Triangular number

## Problem Statement

The triangular numbers (or triangle numbers) are the sequence of positive integers that can be represented as a lattice of points arranged in an equilateral triangle. The triangular lattice representing the nth triangular number contains n rows: the first row contains one point, the second row contains two, and this pattern continues up to the nth row, which contains n.

few triangular numbers are 1,3,6,10...

Given a positive integer N, determine if it is a valid triangular number. Output YES if it is, and NO if it is not.

## Input Format

First line contains a single integer N

## Constraints

1<=N<=10^9

## Sample Input 0

```
15
```

## Sample Output 0

```
YES
```
