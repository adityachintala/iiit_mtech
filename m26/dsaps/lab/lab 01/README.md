| 1 | [Fibonacci Queries](Fibonacci%20Queries.md) | [LeetCode 509 — Fibonacci Number](https://leetcode.com/problems/fibonacci-number/) | Close analog: LeetCode asks for one F(n) with n ≤ 30 and no modulo, while this has up to 10^4 queries with N ≤ 10^6 and answers modulo 10^9 + 7. Greedy: sort by end time and take each interval that starts at or after the last chosen end, O(N log N). |
| 4 | [Maximum Number of Overlapping Intervals](Maximum%20Number%20of%20Overlapping%20Intervals.md) | [LeetCode 2406 — Divide Intervals Into Minimum Number of Groups](https://leetcode.com/problems/divide-intervals-into-minimum-number-of-groups/) | Essentially identical: intervals are inclusive in both, and the minimum number of groups equals the maximum overlap at any point. Use a sweep line (sort starts and ends, starts first on ties) in O(n log n), or a difference array over coordinates up to 4 × 10^6. |
| 5 | [Near the Best](Near%20the%20Best.md) | [LeetCode 231 — Power of Two](https://leetcode.com/problems/power-of-two/) | Loose analog: LeetCode only checks whether n is a power of two, while this asks for the smallest power of two ≥ x. Compute it with bit tricks, e.g. 1 << bit_length(x − 1) (with x = 1 giving 1), in O(1) or O(log x). |
