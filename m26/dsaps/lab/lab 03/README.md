| 1 | [Longest Increasing Subsequence](Longest%20Increasing%20Subsequence.md) | [LeetCode 300 — Longest Increasing Subsequence](https://leetcode.com/problems/longest-increasing-subsequence/) | Identical problem: length of the longest strictly increasing subsequence, n ≤ 2500. | 5 | [The TAs Consult the Stars](The%20TAs%20Consult%20the%20Stars.md) | [LeetCode 264 — Ugly Number II](https://leetcode.com/problems/ugly-number-ii/) | Identical problem: n-th number whose only prime factors are 2, 3 and 5, with 1 as the first (n ≤ 1690). Standard O(n) three-pointer DP (or a min-heap with a set, O(n log n)). |
